# Skill Iterating

> 详细步骤、模板、示例、架构设计模式见 `REFERENCE.md`（完整版），AI 在需要时按需加载。

## 核心理念

**AI 协同编程的核心瓶颈不是 AI 的能力，而是 AI 的记忆。** 本 Skill 的所有规范围绕一个目标：**让每一次有价值的对话都留下"遗产"，让下一轮 AI 能快速进入状态。**

## 治理边界

| 类型 | 协作协议 | 适用场景 |
|------|---------|---------|
| 🧠 元技能 | 全权委托，直接修改源码，提交 | skill-iterating, skill-creator 等个人工具 |
| 📦 产品技能 | 禁止直连源码，Proposal 工作流，人类审核后合并 | 对外发布的 Skill |

## 第零步：流程启动确认

**在已有 Skill 项目中开始任何实质性改动之前，必须先完成：**

1. 确认已读本 Skill
2. 执行冷启动协议（恢复项目上下文）
3. 确认标准流程（评审→测试→Commit→Backlog 更新）

## 一、会话冷启动协议

按顺序恢复上下文：

1. 读 SKILL.md → 2. 读 CHANGELOG.md → 3. `git log --oneline -20` → 4. `git log -1 --format=full` → 5. 读 backlog → 6. 读最近验证报告

## 二、改动后的标准验证流程

| Step | 内容 | 要点 |
|------|------|------|
| 1 | 打包 | 执行 build.sh，开发态→发布态 |
| 2 | 代码评审 | 主 Agent 自审（设计一致性 + 测试缺口检查）→ 可选 Sub Agent 无上下文评审 |
| 3 | Sub Agent 冒烟测试 | 无上下文 Sub Agent 基于发布产物验证，模拟真实查询，结构化评分 |
| 4 | 收集和记录 | 记录评分和改进建议，必须修复的立即处理 |
| 5 | 迭代 | 修复→重新打包→再次验证，直到无阻塞性问题 |

## 三、端到端测试规范（速查）

- 用例分三层：**冒烟**（核心路径）→ **回归**（已修复的 bug）→ **边界**（极端输入）
- 执行方式：真实环境 + 实际调用，输出存档到 `evals/reports/`
- 能力变更时必须同步更新测试用例

## 四、Commit 检查点

- **何时 Commit**：每完成一轮"改动→验证→确认"循环
- **Message 模板**：`{type}({scope}): {描述}` + 改动概要 + 验证结果 + 已知限制
- **何时打 Tag**：多个 commit 构成一个完整功能时

## 五、验证报告持久化

报告存放在 `evals/reports/YYYYMMDD-{简述}.md`，包含：版本信息、测试结果矩阵、改进建议、下一步计划。

## 六、面向 AI 的文档写作原则

写给 AI 读的文档：用结构化格式（表格/列表）、给出正反例、避免模糊表述（"适当"→具体数字）、保持层级清晰。

## 七、Backlog 管理规范

三个核心动作：**冷启动时审查** → **迭代中记录** → **收尾时更新**。格式：`- [ ] {简述} | 来源: {出处} | 优先级: {P0-P2}`

## 八、上下文防护机制

三重防护协同：

| 防护 | 时机 | 机制 |
|------|------|------|
| 第零步检查点 | 会话开始 | 强制执行冷启动协议 |
| Note 锚点 | 工作过程 | todo 的 note 字段记录关键状态 |
| 末尾 todo 项 | 工作结束 | 创建"下次启动时执行"的 todo |

## 九、跨会话连续性检查清单

新会话开始时逐项检查：代码状态一致？Backlog 最新？上次验证结果？未完成的改进？

## 十、Skill 架构设计模式

三层架构：**配置层**（触发 + 参数提取）→ **能力层**（工具 + 推理）→ **知识层**（领域知识按需加载）

## 十一、迭代改进的认知原则

- **泛化而非过拟合**：从反馈中提炼通用规律，不做精确修补
- **重复劳动 = 固化信号**：重复的脚本→scripts/，重复查阅的文档→references/
- **Skill 触发机制**：复杂多步骤查询才可靠触发，description 要"有一点推销性"

## 注意事项

- 本 Skill 适用于任何 Skill 项目，不绑定特定 Skill
- 与 skill-creator 互补：creator 负责 0→1，本 Skill 负责 1→N
- 核心目标：**让下一轮 AI 能快速进入状态，减少重复劳动**
